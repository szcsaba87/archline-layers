# Layer Properties Management (React replica)

Static visual replica of a CAD "Layer Properties Management" dialog.

    npm install
    npm run dev

- `src/data/layers.js` – all sample data (layers, filter tree, variations)
- `src/components/` – `Toolbar`, `LayerTable`, `LayerFilters`, `Variations`, `Footer`, `Icons`
- `src/styles.css` – all styling (no UI library)
